# Day 4: Capstone
## Brief
Produce an A-001 review briefing for a qualified human reviewer, from an evidence packet built from the data, the forecast and the documents.

## Required sections
Eight sections as defined in `BRIEFING_SECTIONS` in `colab/enec_colab.py`. Every claim cites a document or a data query. Draft documents are not authoritative; superseded documents are history; an open work order is not an authorisation.

## Rubric (5 dimensions)
Evidence grounding, authority handling, uncertainty stated, actionability for a human reviewer, clarity. Used by the optional judge in notebook 1, together with the transparent rule-based checks.

Then run notebook 2 for the in-Colab app.
