## Set up Copilot in Excel (do this before the session)
1. Sign in with your official Microsoft account.
2. Save the workbook in **OneDrive or SharePoint** and turn **AutoSave on**.
3. Keep it as `.xlsx`. The data is already formatted as an Excel Table; click inside the table before opening Copilot.
4. Large tables (the log workbooks have 14,000 to 23,000 rows) can take 30 seconds or more. Ask narrow questions.
5. Licence requirements differ. Confirm yours in advance.

## Rules
Synthetic data only. Never paste real plant data into any AI tool. Check every answer against a filter or the check answer. A person decides.
